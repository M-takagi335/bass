# bass
ベースを再現

React・TypeScript・Vite で開発する、日本語のベースTAB譜プレイヤーです。指板表示、JSON の読み込み、自動演奏に対応しています。

## 開発環境

Node.js 20.19 以降の 20.x、または Node.js 22.12 以降と npm が必要です。

## 起動方法

リポジトリのルートで実行します。

```sh
npm ci
npm run dev
```

ブラウザーで [http://localhost:5173](http://localhost:5173) を開きます。ポートが使用中の場合は、ターミナルに表示された URL を開いてください。

同じ Wi-Fi に接続したスマートフォンや iPad から確認する場合は、`npm run dev -- --host` で起動し、ターミナルに表示された `Network` の URL を端末で開きます。

## 使い方

- 起動時にサンプル曲が表示されます。「再生」を押すと音と指板が自動で進み、曲末で停止します。同時発音の音符はまとめて表示します。
- 「一時停止」、再生バー、5秒戻る・進むボタンで再生位置を操作できます。5秒移動は現在の速度で表示される演奏時間が基準です。
- 演奏 BPM は入力を確定すると反映されます。再生倍率と組み合わせて速度を調整でき、音程は一定です。
- 指板は上から G、D、A、E の順です。0 は開放弦です。発音中の音を緑の丸で示し、休符や一時停止中は丸が消えます。タイはひと続きの音として鳴らし、同じ音が続く場合もタイの指定がなければ発音し直します。
- スライダーまたは指板上のピンチ操作で 4〜25 フレット分を表示できます。スワイプ、横スクロール、または指板の左右ボタンで表示範囲を移動できます。
- 「JSON ファイルを開く」で端末内の曲データを読み込みます。不正なファイルを選ぶと日本語のエラーが表示され、読み込み済みの曲を引き続き確認できます。

## 曲データの形式（バージョン 1）

[サンプル JSON](src/sample-song.json) に、開放弦、3連符、休符、同時発音、小節をまたぐタイの例を収録しています。正式なスキーマと検証処理は [src/song.ts](src/song.ts) にあります。

| 項目 | 内容 |
| --- | --- |
| `version` | `1` |
| `title` | 曲名 |
| `bpm` | 1分あたりの四分音符の数 |
| `timeSignature` | `numerator` が分子、`denominator` が分母。曲全体で固定 |
| `ticksPerQuarter` | 四分音符あたりの整数 tick 数。24 の倍数 |
| `tuning` | 弦番号順に `["E1", "A1", "D2", "G2"]` |
| `events` | 音符（`type: "note"`）と休符（`type: "rest"`）の配列 |

各イベントの `measure` は 1 始まり、`startTick` は曲頭を 0 とする絶対位置、`durationTicks` は正の整数です。小節番号と開始位置は拍子に一致させます。音符には弦番号 `string`（1=E、2=A、3=D、4=G）と `fret`（0〜24）を指定します。

- 480 tick を四分音符とした場合、八分音符の3連符は 160 tick ずつです。
- 同じ `startTick` に異なる弦の音符を置くと同時発音になります。同じ弦の音符同士は時間的に重ねられません。
- タイの後続音符には `tieFromPrevious: true` を設定します。直前の音符の終了位置から、同じ弦・フレットで続けます。
- 休符は全弦共通で、他のイベントと重ならない区間に置きます。

## 開発コマンド

| コマンド | 用途 |
| --- | --- |
| `npm run typecheck` | TypeScript の型チェック |
| `npm run build` | 型チェックと本番用ファイルの生成 |
| `npm run preview` | ビルド結果をローカルで確認 |

`package-lock.json` は依存関係の再現に使います。`node_modules/` と `dist/` は Git の追跡対象から除外しています。
